# Security and reporting

Do not publish game executables, saves, personal paths, tokens or credentials in issues.

For a potential vulnerability, use GitHub's private vulnerability reporting if the maintainer has enabled it. Otherwise open a minimal issue requesting a private contact route without exploit details or personal information. For ordinary compatibility bugs, use Issues.

Do not ask users to disable antivirus or claim the app is guaranteed safe. The release binary is unsigned; publish its checksum and source and describe the exact test status.
